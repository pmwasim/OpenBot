# OpenBot v0.4.31 connector management assessment

Date: 2026-08-27  
Release: v0.4.31  
Scope: dashboard connector management.

## Outcome

Operators can now edit a connector in place from the dashboard, matching the existing bot, skill, and memory management experience. The edit uses the existing API validation path, preserves the connector id, and does not change the approval or network boundary.

## Verification

- Dashboard contract now requires and exposes `editConnector`.
- Connector fields remain name, description, base URL, and comma-separated allowed paths.
- Save uses the existing `PATCH /api/connectors/:id` route; cancel restores the connector card without a second identity.
- `npm run check`: 142/142 checks passed.
- Final exact-commit standard security scan: required before publication; release only after complete coverage and zero validated findings.

## Limits

This is connector administration, not a general plugin system. Requests remain read-only GET-only, exact-host/path allowlisted, redirect-disabled, response-bounded, and approval-gated. Signed extensions, richer discovery, OAuth, multi-user authorization, and full MCP compatibility remain future work.
