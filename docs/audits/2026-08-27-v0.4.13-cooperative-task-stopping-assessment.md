# OpenBot v0.4.13 cooperative task-stopping assessment

Date: 2026-08-27  
Scope: cooperative pause/cancel observation in the bounded agent loop  
Audited implementation commit: e5002273c6606b0cf12c6ca71489f5609a9ffc06

## Product result

OpenBot now rechecks durable task state before each model turn, after a model response, and before dispatching an action. If an operator pauses or cancels during a model call, the controller returns the durable paused/cancelled state and does not claim a false completion. This closes the race between dashboard/API task control and the bounded agent loop at its model/action boundaries.

Cooperative stopping cannot undo an action that has already completed; the existing approval gate and worker boundaries remain responsible for controlling consequential effects.

## Evidence

- The fresh release harness passed 95/95 checks after the implementation commit.
- A regression test changes a task to cancelled during a model call and verifies that the controller stops without an `agent.completed` event.
- Existing approval, workspace containment, task recovery, activity, audit redaction, and public-surface brand-neutrality checks remain green.
- `node --check lib/agent.mjs`, `node --check server.mjs`, `node --check public/app.js`, and `git diff --check` passed.
- No runtime dependency, hosted service, account, telemetry, or paid integration was added.

## Older-laptop assessment

The change adds one lightweight durable-state read at each model/action boundary. It does not increase turn/action limits, add polling, start another process, or require a container runtime.

## Security boundary

The controller treats only durable `paused` and `cancelled` states as operator stop signals. It does not accept model-provided control values, bypass policy, or alter approval consumption. The store remains authoritative for state transitions and the existing workers remain bounded to the task workspace.

## Remaining gaps

- Hard cancellation of an already-running worker, native desktop packaging, notifications, full-duplex streaming, multi-user identity, connectors, signed extensions, and remote workers remain incomplete.
