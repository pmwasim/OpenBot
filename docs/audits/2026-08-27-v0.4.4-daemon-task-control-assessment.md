# OpenBot v0.4.4 daemon task-control assessment

Date: 2026-08-27  
Scope: daemon-routed CLI pause, resume, and cancel  
Audited implementation commit: pending final code commit

## Product result

OpenBot's CLI can now route `pause`, `resume`, and `cancel` through the running local daemon with `--daemon`. Pause and cancel use an explicit server control route backed by the existing status-transition table. Resume uses the daemon's existing bounded agent endpoint and can continue a paused task without changing its task identity or event history.

This completes the core interactive task-control path across the shared daemon and CLI. A client can now inspect, observe, approve, reject, pause, resume, or cancel server-owned work without maintaining a second populated local store.

## Evidence

- The release harness passed 87/87 checks, including daemon-routed pause, resume-to-completion, and cancel against a live server.
- The control test uses an empty separate client data directory and confirms state changes occur in the daemon-owned store.
- Resume consumes the server's bounded fixture agent response and returns the original task id; cancel produces the durable cancelled status.
- No runtime dependency, hosted service, account, telemetry, or paid integration was added.

## Older-laptop assessment

Pause and cancel use one bounded HTTP request. Resume uses the existing daemon agent path and does not start a second controller or model process. Direct local commands remain available when the daemon is not running.

## Security boundary

The daemon client keeps the existing bearer-token behavior for explicitly protected non-loopback use. Task ids are URL-encoded, state changes are limited to the server's supported transitions, and resume still passes through the existing task, workspace, model, policy, and audit controls.

## Remaining gaps

- Routine, memory, skill, and bot administration are not yet daemon-routed.
- Full-duplex streaming, notifications, multi-user identity, connectors, desktop automation, and remote workers remain incomplete.
