# OpenBot v0.4.37 skill-pack assessment

Date: 2026-08-27
Scope: portable versioned declarative skill packs

## Outcome

The release adds a usable portability path for operator-owned local guidance. A skill pack can be exported from the dashboard, API, or CLI and imported into another local OpenBot data store without copying the event log or changing task policy. Empty exports are valid, while imports are bounded and duplicate-safe.

## Product assessment

- End-user value: reusable local bot guidance can move between laptops and installations through one human-readable JSON file.
- Old-laptop fit: the feature uses stock Node.js and bounded in-memory parsing; it adds no service, model, network, or paid dependency.
- Public positioning: the implementation and documentation describe OpenBot generically and do not depend on another product or hosted brand.
- Boundary: packs contain text instructions only. They do not install code, add tools, grant permissions, select a provider, or bypass approvals.

## Remaining gap

This is the bounded declarative slice of the broader skills roadmap. Signed manifests, executable extension isolation, permission declarations, fixtures, and a reviewed marketplace are not included and remain release blockers for any future executable-plugin claim.
